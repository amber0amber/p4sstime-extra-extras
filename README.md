# p4sstime-extra-extras
Additional plugins, configs, and maps for the 4v4 PASS Time gamemode.

## teleport_ball.smx
A practice plugin to teleport the ball without needing sv_cheats enabled, and including much more functionality.
### Syntax
```jack_tp [xPos yPos zPos] [xVel yVel zVel]``` --- Teleports the jack to the specified coordinates at the specified velocities. (Uses the player's coordinates if none are specified.)

Prefix an argument with a **+** to indicate a relative argument to the jack.
